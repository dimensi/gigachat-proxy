OpenAI-compatible · GigaChat · Docker

gigachat-proxy

Запустите GigaChat как OpenAI API на своём Mac или Linux — одной командой.

bash
curl -fsSL https://gigachat.dimensi.dev/setup.sh | bash

Как это работает

Один скрипт — полная настройка от нуля до рабочего API

Для чего

GigaChat — мощная российская языковая модель от Сбера, но её API несовместимо с экосистемой OpenAI. Этот прокси устраняет разрыв: любой инструмент, который умеет работать с ChatGPT, автоматически заработает с GigaChat.

Работает с

Raycast AI Cursor Aider Claude Code OpenAI SDK LangChain n8n OpenHands

Что делает скрипт

  1. 1

    Проверяет Docker

    Устанавливает через Homebrew (macOS) или официальный скрипт (Linux), ждёт готовности daemon

  2. 2

    Запрашивает ключ авторизации

    Ввод скрыт. При повторном запуске предлагает оставить текущий ключ

  3. 3

    Создаёт конфигурацию

    Пишет .env, docker-compose.yml в ~/gigachat-proxy/

  4. 4

    Поднимает контейнер и тестирует

    Запускает docker compose up -d и проверяет health, models, chat, streaming
